# WinFulltime - Bookmaker Outreach Templates
## Prepared 19 September 2026

How to use:
- Personalise the first line (mention their brand/site, recent campaign, licence, launch, etc.).
- Send from winfulltime.com domain with SPF/DKIM set up.
- Follow up once after 5-7 business days, then close.
- Use the "Short pitch" for new/expanding operators, the "Affiliate angle" only where they run an affiliate programme.

## Prep checklist before sending

- [ ] Verify the named email is a human (find name on LinkedIn or site staff/contact page where possible)
- [ ] Re-check the licence/status once more (KE GRA transition, NG state-based, GH annual) - don't imply an operator is unlicensed
- [ ] Confirm the recipient runs sports betting (not casino-only) in the target market
- [ ] Fill in maths: put real traffic/social numbers, not #TRAFFIC
- [ ] Set SPF/DKIM/DMARC on whatever sender address you use
- [ ] Offer alternative contact if email is a general mailbox (ask who handles marketing/partnerships)
