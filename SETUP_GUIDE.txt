================================================================================
                    WINFULLTIME SETUP GUIDE
================================================================================

This guide covers setting up:
1. Supabase (Database & Auth)
2. Google Login
3. PayPal Payments
4. Admin Dashboard Access

================================================================================
                    PART 1: SUPABASE SETUP
================================================================================

1. Create Supabase Account
   - Go to https://supabase.com
   - Click "Start your project"
   - Sign up with GitHub or Email

2. Create New Project
   - Name: WinFulltime
   - Database Password: Create a strong password (save this!)
   - Region: Choose closest to your users

3. Get Credentials
   - Go to Project Settings (gear icon) → API
   - Copy "Project URL" - this is SUPABASE_URL
   - Copy "service_role" secret - this is SUPABASE_SERVICE_KEY
   - IMPORTANT: Use the service_role key (not anon key)

4. Setup Database Tables
   - Go to SQL Editor in Supabase dashboard
   - Copy and paste the contents of supabase-schema.sql
   - Click "Run" to execute

5. Enable Google Auth (Optional)
   - Go to Authentication → Providers
   - Click Google
   - Enable: ON
   - Client ID: (see Part 2)
   - Client Secret: (see Part 2)
   - Authorized Domains: Add your domain

================================================================================
                    PART 2: GOOGLE LOGIN SETUP
================================================================================

1. Create Google Cloud Project
   - Go to https://console.cloud.google.com
   - Create new project: WinFulltime

2. Configure OAuth Consent Screen
   - Go to APIs & Services → OAuth consent screen
   - User Type: External
   - Fill in:
     * App name: WinFulltime
     * User support email: your email
     * Developer contact: your email
   - Click Save and Continue through scopes (no need to add any)

3. Create OAuth Credentials
   - Go to Credentials → Create Credentials → OAuth client ID
   - Application type: Web application
   - Name: WinFulltime Web
   - Authorized redirect URIs:
     https://[your-project].supabase.co/auth/v1/callback
   
   For local testing:
     http://localhost:3002/auth/v1/callback
   
   For production:
     https://yourdomain.com/auth/v1/callback

4. Get Client ID and Secret
   - Copy Client ID
   - Copy Client secret
   - Add these to Supabase (Authentication → Providers → Google)

================================================================================
                    PART 3: PAYPAL SETUP
================================================================================

1. Create PayPal Business Account
   - Go to https://paypal.com
   - Sign up for Business account
   - Complete verification

2. Get API Credentials
   - Go to https://developer.paypal.com
   - Log in with your PayPal account
   - Go to Dashboard → My Apps & Credentials
   - Create App:
     * App Name: WinFulltime
     * App Type: Web
   - Copy Client ID
   - Copy Secret

3. Configure in Supabase (Optional - for webhook)
   - For now, payments work through the frontend

================================================================================
                    PART 4: RAILWAY DEPLOYMENT
================================================================================

1. Push Code to GitHub
   - Commit all files
   - Push to your repository

2. Deploy on Railway
   - Connect your GitHub repo
   - Add Environment Variables:

   SUPABASE_URL=https://xxxxx.supabase.co
   SUPABASE_SERVICE_KEY=eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
   PAYPAL_CLIENT_ID=your_paypal_client_id
   PAYPAL_CLIENT_SECRET=your_paypal_client_secret
   PAYPAL_MODE=sandbox
   BASE_URL=https://yourdomain.com
   ADMIN_EMAIL=admin@winfulltime.com
   ADMIN_SECRET=adminsecret123
   GEMINI_API_KEY=your_gemini_key

3. Deploy
   - Click Deploy

================================================================================
                    PART 5: ADMIN SETUP
================================================================================

1. First, register a user account:
   - Go to your site
   - Click Login → Create Account
   - Register with your email

2. Make yourself admin:
   - Visit: https://yourdomain.com/api/admin/setup?email=your@email.com&secret=adminsecret123
   
   You should see: {"success":true,"message":"User is now admin: your@email.com"}

3. Access Admin Dashboard:
   - Go to https://yourdomain.com/admin
   - You should see user management

================================================================================
                    PART 6: GOOGLE AUTHENTICATED REDIRECT
================================================================================

Since we're using Supabase OAuth, update your callback:

In Supabase Dashboard:
- Authentication → URL Configuration
- Site URL: https://yourdomain.com

In Google Cloud Console:
- Add to Authorized redirect URIs:
  https://yourdomain.com/auth/v1/callback
