    How it works & limits

    SportyBet ↔ MSport convert directly because both run on the same betting platform. Bet9ja codes can be decoded and recreated in Bet9ja; converting between Bet9ja and SportyBet/MSport is being rolled out and will be enabled here as soon as the matching feed is ready. Bet9ja code creation currently supports 1X2 selections only.
    Codes support up to 30 selections and expire once the first match in the code kicks off. Only pre-match selections can be converted, and codes are region-locked to Nigeria (NG).
