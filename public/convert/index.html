Booking code conversion FAQ

Is converting booking codes free?

Yes. WinFulltime never charges for decoding, previewing or generating a booking code. You only stake money if you place the converted bet on your bookmaker.

Which bookmakers can I convert between?

SportyBet, MSport, Betway and Bet9ja codes can be decoded, and 1X2 selections can be converted between any two of them. Codes are validated by the target bookmaker before they are returned.

Why is Bet9ja conversion limited?

Bet9ja code creation currently supports 1X2 selections only, and Bet9ja conversion is experiencing issues at the moment. Our technical team is working on it. SportyBet, MSport and Betway conversions are unaffected.

How many selections can a code have?

The maximum is 30 selections per code. Codes above that limit are rejected with a clear message.

How long does a converted code stay valid?

A converted code is valid until the first match on the slip kicks off, so load and stake it before the earliest kick-off.
