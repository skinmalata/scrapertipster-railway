How to convert a Betway code to MSport

  1. Copy your Betway Book-A-Bet code. Copy the booking code from your Betway Book A Bet slip.
  2. Paste it here. Paste the code with the From bookmaker set to Betway.
  3. Choose MSport and convert. Set the To bookmaker to MSport and tap Convert Code.
  4. Load it on MSport. Open MSport and paste the code into the code field to load the slip.

Find your Betway Book-A-Bet code

  1. Open Betway and go to the Book A Bet section.
  2. Create or open the Book-A-Bet slip and copy the booking code it shows.

Load the new MSport share code

Open the MSport app, paste the code into the code entry field and load the slip.

MSport code creation is not limited to 1X2 — any selection MSport still offers can be re-encoded.

Betway to MSport — frequently asked questions

Do all Betway Book-A-Bet codes convert to MSport?

Selections that MSport also offers convert cleanly. Markets unavailable on MSport are flagged during conversion.

Will the odds change on the MSport code?

The selections are re-priced at MSport's current odds, so the combined total can differ from the Betway original.

How many legs can I convert from Betway to MSport?

Up to 30 legs, matching the platform limit for Betway to MSport conversion.
