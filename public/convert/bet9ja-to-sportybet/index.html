Bet9ja to SportyBet — frequently asked questions

Can every Bet9ja code be converted to SportyBet?

Codes built from 1X2 selections convert cleanly to SportyBet. Bet9ja slips using other market types cannot be re-issued to SportyBet yet.

Do I need a Bet9ja account to use the converter?

No — you only need the Bet9ja Book-A-Bet code. Paste it and get a SportyBet share code without logging in.

What happens to the odds on the new SportyBet code?

The selections carry over at SportyBet's current prices, so the total odds on the new SportyBet code may differ slightly from the Bet9ja original.

How many legs can a Bet9ja slip have when converted?

Up to 30 legs are supported for Bet9ja to SportyBet conversion.
