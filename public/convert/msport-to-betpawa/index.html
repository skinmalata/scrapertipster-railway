How to convert a MSport code to betPawa

  1. Copy your MSport share code. Open the slip in the MSport app, tap Share, and copy the share code it displays.
  2. Paste it here. Paste the code and confirm the From bookmaker is set to MSport.
  3. Choose betPawa and convert. Set the To bookmaker to betPawa and tap Convert Code.
  4. Load it on betPawa. Open the betPawa app, tap Load Code, paste the generated code and the slip loads ready to stake.

MSport to betPawa — frequently asked questions

Can an MSport 1X2 slip become a betPawa code?

Yes. Each MSport match is matched to the betPawa event feed and a fresh betPawa code is minted from the 1X2 selections.

Do all MSport markets convert to betPawa?

A betPawa code is built from the match-result market, so the 1X2 legs of your MSport slip convert and any other markets are reported.

How many legs can an MSport to betPawa code have?

Up to 30 legs are supported for an MSport to betPawa conversion.

Is converting an MSport code to betPawa free?

Yes, generating the betPawa booking code is free; you only stake if you place the bet on betPawa.
